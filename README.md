# Personal Portfolio

A polished static portfolio site for GitHub Pages, inspired by the structure and energy of [soumyajit4419/Portfolio](https://github.com/soumyajit4419/Portfolio), but rebuilt here as a lightweight one-page site with no build step.

## Publish on GitHub Pages

1. Create a repository named `your-username.github.io`.
2. Put these files at the repository root.
3. Commit and push to the `main` branch.
4. Open `https://your-username.github.io`.

## Customize

- Update the name, links, email, and section text in `index.html`.
- Replace `assets/hero-workspace.png` with your own hero image if you want a more personal visual.
- Add a real PDF resume under `assets/` and update the resume link.
- Replace the project cards with real repositories, demos, papers, or writeups.

## Local Preview

Open `index.html` directly in a browser. No package install is required.
